Security Verification:

1. Password is not stored as plain text.

3. A random salt is generated for each password.
4. Password input is hidden using getpass.
5. Empty username and password inputs are rejected.
6. Password comparison uses secrets.compare_digest().
7. Incorrect login attempts return a generic error message.
